## Full description (Description field)

### Techguns Expanded

**Techguns Expanded** is an add-on that extends [Techguns](https://www.curseforge.com/minecraft/mc-mods/techguns) with a proper energy progression and a line of new endgame materials. It fills a gap in the base mod: a reason to build power infrastructure, and the tech-tree materials to spend that power on. Everything is crafted and researched through Techguns' existing machines, so it feels like part of the same mod rather than a bolt-on.

> **Requires Techguns.** This is an add-on, not a standalone mod. You must have Techguns installed or the game will not load. See *Requirements* below.

---

### Power generation

The core of the mod is a tiered line of **Fuel Generators** that burn ordinary furnace fuel (coal, blocks, buckets of oil, etc.) and output **RF / Forge Energy** — compatible with any tech mod that uses the standard energy system.

Each tier is crafted from the one below it, so upgrading is a natural progression rather than starting over:

| Generator | Relative output | Notes |
|---|---|---|
| Fuel Generator Mk1 | Baseline | Early-game starter |
| Fuel Generator Mk2 | ~1.5× Mk1 | Built from Mk1 |
| Fuel Generator Mk3 | ~2.2× Mk1 | |
| Fuel Generator Mk4 | ~3.5× Mk1 | |
| Fuel Generator Mk5 | ~5× Mk1 | |
| Fuel Generator Mk6 | ~10× Mk1 | Top burnable tier |
| Creative Generator | Infinite | Creative / testing — endless RF output |

Output rates scale cleanly across the whole line, and each generator's transfer rate scales with its tier so higher tiers actually deliver their extra power instead of choking on a shared cap. All generators can be broken with any tool (or by hand) and have the same durability as a normal machine block.

### New ore and materials

**Tungsten Carbide Ore** generates in the Nether and requires a **diamond pickaxe** to mine. It's the gateway to the mod's material tree:

- **Tungsten Carbide Ingot** & **Tungsten Carbide Block** — the base crafting material
- **Thumb Tungsten Ore** — a refined intermediate, produced in the Reaction Chamber
- **Diamond Wire** — pressed from gold wire and a diamond
- **Titanium Superwire** and **Anoda Technology Superwire** — advanced wiring for high-tier builds
- **Ultratanium Ingot** — a top-tier alloy fabricated from diamond, uranium, and tungsten carbide
- **Enriched Uranium Block** — compact nuclear material
- **Creative Mechanism Block** — the key component of the Creative Generator
- **Cooling Liquid Bottle** — a crafted utility consumable
- **Oil** (fluid) & **Bucket of Oil** — integrates with Techguns' oil system

---

### Machines and integration

- **Advanced Metal Press** — a new processing machine
- New recipes wired directly into Techguns' own machines — the **Metal Press**, **Fabricator**, **Reaction Chamber**, and **Chem Lab** — so the new materials use the workflows players already know

---

### Requirements

- **Minecraft 1.12.2**
- **Minecraft Forge**
- **Techguns** *(required — install it alongside this mod)*

**Optional:** JEI is recommended so you can browse all the new recipes in-game. Any mod that uses RF / Forge Energy can consume power from the generators.

---

### Notes

All items and blocks appear on the **Techguns** creative tab. World generation for Tungsten Carbide Ore applies to newly generated Nether chunks only — existing chunks won't retroactively contain the ore.
